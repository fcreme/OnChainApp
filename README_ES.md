# OnChain — Motor de Conciliación Blockchain

## README en Español

Una plataforma de conciliación blockchain de nivel fintech que compara transacciones on-chain con registros off-chain mediante un motor de puntuación explicable.

## Resumen
OnChain resuelve el problema de verificar que cada registro financiero interno tenga una transacción correspondiente en blockchain.

## Características principales
- Motor de conciliación explicable.
- Detección de desviaciones (drift).
- Puntuación de riesgo de billeteras.
- Historial de auditoría inmutable.
- Integración con Ethereum Sepolia.

## Stack Tecnológico
- React
- TypeScript
- Node.js + Express
- PostgreSQL
- Viem / Wagmi
- Vite

## Instalación

```bash
git clone https://github.com/fcreme/OnChainApp.git
cd OnChainApp
npm install
```

## Ejecución

```bash
npm run dev:all
```
